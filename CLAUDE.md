# Правила для ассистента

Проект — игра на Roblox (Luau), код синхронизируется со Studio через Rojo.
Структура и правила описаны в README.md.

- Отвечай и пиши комментарии в коде на русском языке.
- Каждый файл начинается с `--!strict`.
- Сервер авторитарен: клиент присылает намерения, сервер проверяет и считает
  результат. Каждый новый Remote объявляется в `src/shared/Remotes.luau`
  и обрабатывается только через `NetService:on` с проверками `Guard`.
- Данные игрока меняются только через `DataService:set / increment / update`.
  Новые поля добавляются в `DataTemplate`, смена формата — через `Migrations`.
- Объекты с общим поведением обслуживаются через CollectionService (теги),
  а не скриптами внутри деталей.
- В каждом ответе с механикой явно указывай риски эксплойтов и как они закрыты.
